# DevSpaces screenshots

This directory contains the latest screenshot gallery generated by the **DevSpaces Screenshots** GitHub Actions workflow from `master`.

The workflow keeps two copies of each run:

- a short-lived GitHub Actions artifact for every PR/push run;
- the latest successful `master` screenshots committed here for easy browsing from the repository.

Generated contents include the scenario PNG files, `index.html`, `manifest.json`, and `fork-devspaces-diff.txt`.

Do not edit generated images or gallery metadata by hand. They are replaced by CI after a successful screenshot capture on `master`.
